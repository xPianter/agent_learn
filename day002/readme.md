# Day 002 — Python OOP & Tool Abstraction

## 1. 项目目标

通过 Python 面向对象编程，实现一个简单的 Agent 工具调用系统，理解继承、抽象类、方法重写、异常处理和多态。

## 3. 核心设计

* `BaseTool`：工具抽象基类，定义工具名称、描述和 `run()` 接口。
* `SearchTool`：模拟搜索工具，检查输入并返回搜索结果文本。
* `CalculatorTool`：解析两个数字并计算它们的和，处理参数数量和数字格式错误。
* `DatabaseTool`：使用内存中的模拟数据查询用户信息，并处理空 ID 和不存在的用户。
* `Agent`：管理工具列表，根据工具名称调用相应工具，并处理未知工具名称和重复名称。

各工具继承 `BaseTool` 并实现自己的 `run()` 方法。Agent 面向统一接口调用工具，由 Python 根据实际对象类型执行对应的实现。

## 6. 算法：Valid Parentheses

使用栈判断括号字符串是否有效。

* 遇到左括号：入栈。
* 遇到右括号：检查栈是否为空，以及栈顶是否与当前右括号匹配。
* 匹配成功：弹出栈顶；不匹配：返回 `False`。
* 遍历结束后，栈为空才返回 `True`。

时间复杂度：`O(n)`

辅助空间复杂度：`O(n)`
